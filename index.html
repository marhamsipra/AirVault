Core Features

Engineered for seamless local connectivity.

Designed by Muhammad Arham to bring effortless wireless file sharing to standard external hard drives.

Wireless Transfer

Share high-resolution photos, 4K videos, and large documents over fast 5GHz Wi-Fi without needing physical cables.

Samba & NFS Protocol

Low Power Efficiency

System Architecture

How AirVault Works

Architected by Muhammad Arham for high reliability and simplicity.

USB External HDD / SSD

Formatted in NTFS, ext4, or exFAT. Connected via USB 3.0 to provide raw storage capacity.

Raspberry Pi Controller

Runs Samba SMB services and manages power, mounting, network routing, and user access control.

Client Devices

Laptops, smartphones, tablets, and Smart TVs access files instantly over the local Wi-Fi connection.

Technical Specifications

Project Stack & Requirements

Hardware Requirements

  • SBC Model Raspberry Pi 4 / Pi 3B+ / Pi Zero 2W
  • Storage Interface USB 3.0 / USB 2.0 External HDD or SSD
  • Power Supply 5V / 3A Type-C Adapter (Recommended)
  • Wireless Band 2.4GHz / 5GHz Wi-Fi Support

Software & Protocols

  • Operating System Raspberry Pi OS (64-bit Lite / Desktop)
  • File Sharing Protocols Samba (SMB/CIFS) / NFS / DLNA
  • Supported Filesystems ext4, NTFS, exFAT, FAT32
  • Project Lead Muhammad Arham
